## Selected Academic Projects

### 1. Smart Biofloc Aquaculture Monitoring and Management System (Major Project)
*Undergraduate Major Project | S7–S8 B.Tech CSE (Data Science) | Group Project*  
*Technologies: Python, FastAPI, QuestDB, Eclipse Mosquitto (MQTT), Docker Compose, Redis, LightGBM, React, TypeScript*

- Collaborated in a four-member engineering team developing a software-driven aquaculture monitoring and control platform for zero-water-exchange biofloc systems.
- Developed the asynchronous FastAPI backend service, including MQTT consumer handling via Eclipse Mosquitto and edge ingestion webhooks.
- Implemented high-throughput time-series persistence into QuestDB using the Influx Line Protocol (ILP) over TCP sockets.
- Integrated the LightGBM predictive dissolved oxygen forecasting module (2-hour lookahead) and an ADWIN-inspired streaming forecast error monitor into the backend API.
- Integrated the frontend Action Center view in React and TypeScript, exposing live water level metrics, variable aeration controls, sludge evacuation pumps, and chemical dosing indicators with safety interlocks.
- Configured multi-container orchestration across 7 services using Docker Compose and implemented automated API/integration tests.
- *Hardware demarcation:* Physical probe selection, ESP32 wiring, and microcontroller firmware were developed by teammates.

### 2. Pollution Hotspot Detection System Using Clustering and GIS Mapping (Mini-Project)
*Undergraduate Mini-Project | Completed March 2026 | Group Project (Academic Archive)*  
*Technologies: Python, FastAPI, Scikit-learn, SQLite, SQLAlchemy, Leaflet.js, Chart.js, Docker*

- Collaborated in a four-member team to design and document an end-to-end full-stack web application locating air pollution hotspots across India.
- Contributed to the FastAPI REST backend service layer, OpenAQ real-time data ingestion routines, and data normalization via `StandardScaler`.
- Implemented the official CPCB sub-index breakpoint equations to compute station-level AQI across $\text{PM}_{2.5}$, $\text{PM}_{10}$, $\text{NO}_2$, and $\text{SO}_2$.
- Implemented the K-Means unsupervised clustering workflow with Elbow Method evaluation to partition monitoring stations into spatial-intensity risk zones.
- *Archival status:* Preserved as an academic specification and technical archive; original report and certified documentation maintained in institutional records.
